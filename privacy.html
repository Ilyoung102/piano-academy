2. 마이크 접근과 처리

마이크는 사용자가 허밍·연주 입력 기능을 시작하고 권한을 허용할 때 음높이를 추정하기 위해 사용됩니다. 권한을 거절해도 다른 연주·연습 기능을 사용할 수 있습니다.

실시간 음계는 기기 메모리에서 분석합니다. 정밀 변환은 녹음 중 원음의 임시 PCM을 앱 전용 캐시에 기록하고, 변환을 마치거나 취소하면 지웁니다. 비정상 종료로 남은 임시 파일은 다음 실행에서 정리합니다. 앱은 원음을 사용자가 다시 재생할 녹음 파일로 보관하거나 자체 서버로 업로드하지 않습니다. 생성된 음표와 타이밍은 기기에 초안으로 저장될 수 있습니다. 앱이 백그라운드로 이동하면 마이크 입력을 중지합니다.

3. 파일 가져오기와 변환 초안

시스템 파일 선택기로 고른 MIDI·MusicXML·XML·MD 악보와 지원 오디오 파일을 기기에서 처리합니다. 음원 분석에 사용하는 임시 PCM은 앱 전용 캐시에 기록되며 처리 종료 후 삭제됩니다. 앱은 원본 오디오 파일을 수정하거나 자체 서버로 업로드하지 않습니다.

음원·마이크 입력에서 생성한 변환 초안과 편집 내용은 앱 내부 저장소에 자동 저장되며, 앱을 다시 실행하면 복구할 수 있습니다. 자동 저장은 짧은 지연 후 수행되므로 저장 완료 전 강제 종료나 저장 공간 부족 시 최신 변경을 잃을 수 있습니다.

초안을 저장하면 녹음·변환 악보 목록에 남습니다. 초안 폐기 또는 저장 완료 시 복구용 초안을 삭제합니다. 앱은 마지막 변환 초안을 복구하며, 일반적으로 해당 초안을 저장·폐기하거나 앱 데이터를 지우거나 앱을 삭제할 때까지 보관합니다.

4. 보관·삭제·기기 이전

녹음 및 변환 악보는 주로 앱 전용 외부 저장소에, 변환 초안과 설정은 앱 내부 저장소에 보관합니다. 여기서 녹음 악보는 음표 이벤트 자료이며 마이크 원음 파일이 아닙니다.

앱의 자동 클라우드 백업과 Android 기기 간 자동 이전은 비활성화되어 있습니다. 기기 교체나 앱 삭제 전에 필요한 악보를 내보내세요. 악보 내보내기는 전체 설정·점수·연습 기록의 백업을 뜻하지 않습니다.
